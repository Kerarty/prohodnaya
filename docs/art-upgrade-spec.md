# Спецификация визуального апгрейда «Мульт-поп»

Игра: «Проходная» · 720×1280 портрет · Phaser Graphics, ноль растровых ассетов
Статус: направление утверждено клиентом 2026-11-15. Шрифт Balsamiq Sans скачан (4 субсета, ~98 КБ).

---

## 1. Замысел и муд

Громкий плоский мультфильм: толстая чернильная обводка на всём, сочные заливки, лампочная вывеска, гости с характером — дышат, моргают, радуются и обиженно сдуваются. Стиль держится на одном приёме: **контур отделяет фигуру от любого фона**, поэтому фон может быть любым тёплым и светлым, а силуэты и читаемость признаков не теряются. Анти-Papers, Please достигается не «милыми деталями», а физикой мира: пружинящие кнопки, bounce-входы, конфетти — мир доброжелателен на уровне анимации, а не декора.

**Правило нейтральности декора (жёсткое, проверяется при приёмке).** Эмоции — рот, брови, щёки — НЕ являются признаками и не могут стать ими:
1. Только цвета `INK #33254e` и `CHEEK #ff9bb0` — никогда цвета гостевой палитры.
2. Одинаковые у всех гостей: не попадают в `CharacterAttrs`, не генерируются в `generation.ts`, не варьируются.
3. Меняются только ПОСЛЕ вердикта (брови-домик, грусть), пока идёт сверка — лицо нейтральное у всех.
4. Площадь любой декоративной детали ≤ 30% площади наименьшего признака (глаза). Признаки (6 цветов, 4 головы, 3 тела, глаза, аксессуары) не перекрывать и не тонировать.

## 2. Тема — `src/render/theme.ts`

```ts
export const THEME = {
  BG_WALL:  0xffedd3, PANEL: 0x4d7cff, ACCENT: 0xff7a3d,
  SUCCESS:  0x3ec46d, ERROR:  0xff4757, PAPER:  0xffffff,
  INK:      0x33254e, GOLD:   0xffc93c,
  BG_FLOOR: 0xffd9a0, NICHE: 0xfff3e0, NICHE_FLOOR: 0xffe0b3,
  COUNTER_TOP: 0x4d7cff, COUNTER_BODY: 0xff9f68,
  ACCENT_DARK: 0xf0622a, PANEL_DARK: 0x3d63cc, CHEEK: 0xff9bb0, CLOUD: 0xffffff,
  SHADOW_A: 0.20, GUEST_SHADOW_A: 0.18, BULB_OFF_A: 0.35, FLASH_A: 0.12,
} as const;

export const FONT = '"Balsamiq Sans", Arial, sans-serif';
export const INK_HEX = '#33254e';
```

Гостевые 6 цветов НЕ дублируются — остаются в `attributes.ts` (`COLOR_HEX`). Все обводки — `INK`.

Типографика: весь белый текст на акценте/панели — с ink-обводкой 3px (`setStroke`). Минимальный текст 18px. Тела правил 22px, значения пропуска 21–24px bold, штамп 34px letterSpacing 3, кнопки 32px bold uppercase.

## 4. Treatment по зонам (координаты 720×1280)

### 4.1 Фон-сцена (`drawBooth()` в GameScene, depth −10)
- Стена 0,0→720×820 `BG_WALL`; пол 0,820→720×460 `BG_FLOOR`, стык — ink 3px alpha 0.12.
- Ниша гостя roundRect 160,252→400×328 r24 `NICHE` stroke ink 4; пол ниши 176,440→368×124 r16 `NICHE_FLOOR`.
- Облака: 3 капсулы 90×28 `CLOUD` alpha 0.7: (70,300), (575,270), (85,465).
- Стойка: столешница 0,1032→720×28 r6 `COUNTER_TOP` stroke ink 4; фронтон 0,1060→720×220 `COUNTER_BODY`.
- Вывеска на фронтоне: roundRect cx360 cy1240 → 260×64 r14 `PANEL` stroke ink 4; «ПРОХОДНАЯ» 700 28 white stroke ink 3; 10 лампочек d=10 `GOLD` вдоль краёв.
- Тень гостя: эллипс (360, 472) rx95 ry14 ink alpha 0.18 — в фоне, вне контейнера гостя.
- Patience-бар / счётчик / детектор — поверх фронтона, свои места (1010/1050), скин: `PAPER` + ink 4.

### 4.2 Доска правил (`ruleBoard.ts`)
- width 560, cy=130, высота 64 + N×56 (не менять формулу). `PAPER`, stroke ink 5, r=20, hard-тень.
- Заголовок: плашка `ACCENT` 320×40 r10 у верхней кромки, «ПРАВИЛА» 700 26 white stroke ink 3.
- Строки: буллет-кружок d10 `ACCENT`, текст 400 22 `INK_HEX`, пиктограмма справа ink.
- Лампочки: 8 кружков d8 `GOLD` по периметру. `pulse()`: scale 1→1.04→1 + волна лампочек.

### 4.3 Гость (`characterRenderer.ts`)
Порядок слоёв: ботинки → тело/голова → щёки → рот → eyesG (глаза отдельным Graphics) → брови → кольцо подсветки → облачко.

P0: глаза +15% (dots r9, bars 23×8) в `eyesG` + моргание (перерисовка scaleY 0.15, 90мс, каждые 2.5–5с); тень-эллипс в фоне (сдвиг ±0.04, противофаза дыханию); ботинки 2 эллипса 34×16 `INK` (±30, 112); щёки r10 `CHEEK` alpha 0.45 (±34, headCy+16); дыхание scaleY 1→1.012 yoyo 1600ms.
P1: рот-дуга r10 lw3.5 `INK` (0, headCy+28) — улыбка у всех, после вердикта переворот (грусть); брови 18×5 (±16, headCy−36) только в реакции (домик ±18° / приподняты); bounce-вход slide −420→360 (260ms Quad.easeOut) + scale Back.Out 320ms; «сдувание» отказника scaleY 0.88/scaleX 1.06 (140ms) hold 400мс → уход с rotation ±10°; облачко «?!» капсула 120×54 локально (125, −140), pop 200мс, живёт 900мс.
P2 (резать первыми): idle-wobble rotation ±1.5°; «ремень» на rect-теле.

Подсветка полей: кольцо `GOLD`; красный overlay `ERROR` alpha 0.22; API `flashField`/`softHighlight` не менять.

### 4.4 Пропуск (`passCard.ts`)
- 300×420 `PAPER` stroke ink 5 r18 + hard-тень; шапка `ACCENT` 300×64 (верхние углы r18) с «ПРОПУСК» 700 26 white stroke ink 3.
- Перфорация: 8 кружков d8 ink alpha 0.15, x=left+22.
- Поля: значения 700 21–24, подписи 400 19; отступ от перфорации ≥48.
- Штамп: рамка 5px r10, текст 700 34 letterSpacing 3 rotate −12°, scale 2.4→1 Back.Out 180мс + squash (1.15/0.85→1, 120мс) + `camera.shake(120, 0.004)`, в центре карты.
- Подсветки: `ERROR` 0.22 / `GOLD` — только константы.

### 4.5 Кнопки (`button.ts`)
- roundRect r=22, тап-зоны сохранены. Слои: hard-тень → fill + stroke ink 4 → текст 700 32 uppercase white stroke ink 3.
- **Squash**: `pointerdown` → `setScale(1.08, 0.9)`; up/out → tween (1,1) 90мс Back.Out.
- Состояния: primary `ACCENT` (+`ACCENT_DARK` при удержании — опционально), secondary `PAPER` + ink-текст, disabled alpha 0.45.

### 4.6 Кабинет и итоги (`MenuScene.ts`, GameScene.finish)
- Фон — тот же booth (упрощённый). Логотип: плашка 480×110 cy150 `PANEL` stroke ink 5, «ПРОХОДНАЯ» 700 56 white stroke ink 4, 14 лампочек d12 по периметру, волна каждые 4с.
- Карточки-строки `PAPER` stroke ink 4 r16 + hard-тень, stagger-въезд 60мс.
- XP-бар: рамка ink 4 r12, заполнение `ACCENT` с полосами white alpha 0.25 (45°).
- Жетоны: круг `GOLD` stroke ink 4 + ободок + блик.
- Итоги: панель 600×720 `PAPER` stroke ink 5 r24, заголовок на плашке `ACCENT`.
