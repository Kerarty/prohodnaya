# План первой игры для Яндекс Игр

**Цель:** опыт / портфолио — пройти полный цикл (дизайн → разработка → интеграция SDK → релиз).
**Ресурсы:** соло-разработчик с опытом в программировании, JS/TS, горизонт ~4–8 недель вечерами.
**Дата:** 2026-11-09

---

## 1. Контекст платформы (рынок 2025)

- Яндекс Игры — HTML5-игры в браузере, десктоп + мобильные (тач + мышь), RU-аудитория, широкая казуальная.
- Популярные жанры веба: **аркады, головоломки, idle-проекты, фермы**.
- В 2025 платформа удалила ~10 000 непопулярных игр и внедрила **новый алгоритм оценки качества** — выигрывают игры с хорошим ретеншеном и доведённым UX.
- Монетизация: rewarded-видео (за бонусы), interstitial (на логических паузах). Платежи — только с серверной частью, для v1 откладываем.
- SDK: облачные сейвы (лимит 200 КБ), лидерборды (int32), реклама, язык игрока.
- Требования: русский язык обязателен, быстрая загрузка (цель ≤ 5–10 МБ до играбельности), никаких внешних ссылок, пауза звука при потере фокуса.

## 2. Концепции (безопасно → оригинально)

Полные описания кор-лупов, меты, монетизации, скоупа и рисков — в разделах ниже.

| # | Концепция | Жанр | Недели | Портфолио | Риск недоделать | Потенциал у Яндекса | Арт |
|---|---|---|---|---|---|---|---|
| 1 | **Кладовка** | блок-паззл + заказы | 5–6 | 3/5 | низкий | высокий, но много клонов | простой |
| 2 | **Проходная** ⭐ | инспектор-сим | 5–7 | 5/5 | средний | высокий, ниша пуста | процедурный |
| 3 | **Цех №7** | layout-idle | 6–7 | 4/5 | средне-высокий | высокий (топ-жанр) | простой |
| 4 | **Мирокрут** | крути мир, не шарика | 6–7 | 5/5 | средне-высокий | средне-высокий | геометрия |
| 5 | **Эхо** | дейли-гонка с призраком | 5–6 | 5/5 | средний | средний | простой |

**Рекомендация гейм-дизайнера:** топ-1 «Проходная», топ-2 (страховка) «Кладовка».

### 2.1 «Кладовка» — безопасная ставка

**Pitch.** Разбираешь завалы на складе: ставишь фигуры на сетку 9×9, собираешь линии — собранное улетает в коллекцию и выполняет заказы покупателей. Block Blast + доска заказов из ферм.

- **Хук:** очистка линии — источник мета-прогресса (коллекция + заказы), а не просто исчезновение. Два проверенных паттерна веб-казуала в одной игре.
- **Кор-луп 30 сек:** поставил фигуры → собрал линию → предметы улетели в амбар → прогресс заказа.
- **Кор-луп 1 час:** серия партий → закрыл заказы → дневное задание → новая категория предметов.
- **Мета:** коллекция предметов с редкостями, уровень склада, ежедневный стрик. Лидерборд: недельный рекорд. Заказы начисляются от очков партии (иначе — вырожденный фарм).
- **Управление:** drag&drop, фигура приподнимается над пальцем на 60–80 px.
- **Монетизация:** rewarded — вторая жизнь, замена фигуры, ×2 монеты, бустер-молот. Interstitial — после партии, не чаще 1/2–3 партии.
- **Скоуп v1:** без косметики склада, апгрейдов, 2 из 4 бустеров, событий.
- **Риски:** жанр перенасыщен клонами — успех упирается в полировку заказов-меты. Технических рисков почти нет.

### 2.2 «Проходная» ⭐ — смелая

**Pitch.** Дежурный на проходной: за смену проверяешь существ по правилам дня, сверяя 2–3 признака с доской инструкций. Своих — пропустить, самозванцев — развернуть.

- **Хук:** «инспектор документов» (Papers, Please) доказал виральность, но в вебе ниша пуста. Персонажи генерируются из геометрических примитивов по сиду — ноль затрат на арт, бесконечная вариативность.
- **Кор-луп 30 сек:** заявка → сверил признаки с правилами → штамп/отказ → мгновенный фидбек с объяснением ошибки.
- **Кор-луп 1 час:** смена из 12–15 заявок → зарплата → покупка инструментов → новая смена с новым типом правил. 3 ошибки — смена прервана.
- **Мета:** звание/допуск, каталог открытых правил и аномалий, инструменты. Ежедневная смена с общим сидом. Лидерборд: стрик верных решений, рекорд дневной смены.
- **Управление:** тап по кнопкам-штампам, тап по документу — приближение. Порог входа нулевой.
- **Монетизация:** rewarded — прощение ошибки, детектор-подсказка, ×2 зарплата, ночная смена. Interstitial — строго между сменами.
- **Скоуп v1:** без сюжета (каркас правил), 2 инструмента, без призов дневной смены.
- **Риски:** нужен каталог 20–30 типов правил с эскалацией; жёсткий потолок ≤ 3 активных правил одновременно; каждая ошибка обязана объясняться.
- **Почему Яндекс:** формат «найди нарушение» родной РУ-аудитории; виральность («я пропустил двойника — попробуй»); офисные узнают свою проходную.

### 2.3 «Цех №7» — layout-idle

**Pitch.** Мини-фабрика из станков на сетке цеха: цепочки превращают сырьё в продукцию, доход капает офлайн. Расстановка — не косметика, а главная механика.

- **Хук:** веб-idle обычно экран цифр; здесь layout влияет на доход (соседние станки = множители). «Тетрис-экономика» внутри idle.
- **Кор-луп 30 сек:** собрал доход → купил/переставил станок → мгновенно виден рост «доход/мин».
- **Кор-луп 1 час:** дорогой станок → вписал в композицию → оптимизировал → закрыл контракт → новый чертёж.
- **Мета:** офлайн-доход между сессиями (прямое попадание в требование платформы), чертежи, стрик контрактов. Лидерборд: доход/час.
- **Монетизация:** rewarded — ×2 офлайн-доход (сильнейший в жанре), мгновенный контракт, «сверхурочная смена», бесплатный станок.
- **Скоуп v1:** без престижа (после релиза), 10 станков вместо 15+, без декора.
- **Риски:** самая математическая концепция — легко сломать экономику; layout-бонусы не должны наказывать новичков (нужен «авто-советник расстановки»); офлайн-доход считать формулой, не тиками.

### 2.4 «Мирокрут» — крути мир, а не шарика

**Pitch.** Управляешь не шариком, а миром: тап по левой/правой половине экрана поворачивает уровень на 90°, шарик катится по гравитации к выходу.

- **Хук:** инверсия классического управления почти не встречается в вебе, читается мгновенно, один палец. Уровни — из чанков с метаданными решений: бесконечный контент без ручного левел-дизайна.
- **Кор-луп 30 сек:** 1–3 уровня по 20–40 поворотов: повернул → покатился → собрал звёздочку → выход.
- **Мета:** звёзды, главы сложности, ежедневный марафон с общим сидом. Лидерборд: минимум поворотов / время.
- **Монетизация:** rewarded — подсказка следующего поворота (из метаданных чанка), откат хода, пропуск уровня, трейл. Interstitial — только после марафона, никогда между уровнями.
- **Скоуп v1:** одна цветовая тема, ≤ 3 физических gimmick'ов, без редактора уровней.
- **Риски:** вращение создаёт тупики — нужен мгновенный рестарт и обучение микро-чанками; конструктор чанков + гарантия решаемости стыковок — самая «программистская» работа (для портфолио золото).

### 2.5 «Эхо» — гонка против вчерашнего себя

**Pitch.** Каждый день генерируется один трек из даты-сида. Гоняешь против «эха» — призрака своего вчерашнего заезда — и пытаешься обогнать.

- **Хук:** асинхронное соревнование без мультиплеера и своего сервера: призраки в облачных сейвах, общий дневной сид + лидерборд = соревнование со всей платформой. Противник — ты вчерашний.
- **Кор-луп 30 сек:** заезд 40–70 сек, одно действие: удержание = ускорение, отпускание = торможение (физика «флоу», как Tiny Wings).
- **Мета:** призраки и рекорды по датам, стрик дней (дневной трек = причина возвращаться). Лидерборд: время дневного трека.
- **Монетизация:** rewarded — чекпоинт-воскрешение, «медленное эхо» (тренировка на ×0.5), ×2 медали, скин призрака.
- **Скоуп v1:** без скинов, «призраков друзей» (нужен бэкенд — вне скоупа), сезонных треков.
- **Риски:** «против себя» мотивирует не всех (нужны промежуточные медали на треке); одно-кнопочная физика обязана быть очень приятной — самая итерационная часть; трек — по шаблонам, не чистый рандом.

## 3. Технологический стек (рекомендация техдиректора)

**Выбор: `Phaser 3 + TypeScript (strict) + Vite + ESLint/Prettier + Vitest`.**
Запасной: PixiJS 8 (если упрёмся в вес/перфоманс — маловероятно). Phaser 4 — апгрейд для следующего проекта, не для первого релиза.

| | Скорость разработки | TS-типизация | Вес (gzip) | Доки/примеры | Риск |
|---|---|---|---|---|---|
| **Phaser 3** | высокая | зрелая | ~0,35 МБ | ~2000+ примеров, все туториалы по Яндекс Играх на нём | низкий |
| Phaser 4 | высокая | встроенная | ~0,35 МБ | мало примеров/плагинов | средний |
| PixiJS 8 | низкая (рендерер, не движок) | отличные | ~0,15 МБ | «как сделать игру» — сам | высокий |
| KAPLAY | высокая | first-class | ~0,1 МБ | маленькое коммьюнити | средний |
| Canvas | очень низкая | — | 0 | — | очень высокий |

### Ключевые решения

- **Vite:** `base: './'` (относительные пути — требование хостинга Яндекса), `target: 'es2017'`.
- **Тесты:** Vitest только для чистой логики вне Phaser (счёт, экономика, генерация, сериализация сейва). Никаких e2e для этого скоупа.
- **Изоляция SDK — главный архитектурный ход:**

```ts
interface PlatformAPI {
  init(): Promise<void>;
  getLang(): string;
  save(data: SaveData): Promise<void>;       // облако / localStorage
  load(): Promise<SaveData | null>;
  showRewarded(onReward: () => void): Promise<'shown' | 'failed'>;
  showInterstitial(): Promise<void>;
  submitScore(board: string, score: number): Promise<void>;
  onStateChanged(cb: () => void): void;      // пауза при рекламе/потере фокуса
}
```

  - `LocalPlatform` — сейвы в localStorage, rewarded мгновенный с фейковой задержкой 3 сек → игра локально играбельна без интернета.
  - `YandexPlatform` — реальный SDK; выбор по `typeof window.YaGames !== 'undefined'`.

### Интеграция Yandex SDK (v1)

| Метод | Нюанс |
|---|---|
| `YaGames.init()` | sdk.js должен загрузиться ДО вызова |
| `environment.i18n.lang` | обязательная локализация RU (+EN) |
| `LoadingAPI.ready()` | звать, когда игрок реально может играть |
| `GameplayAPI.start()/stop()` | разметка геймплея |
| `player.getData/setData` | лимит 200 КБ; сохранять по visibilitychange/pagehide + троттлинг 10–30 сек |
| `adv.showRewardedVideo` | награда в `onRewarded`, не `onClose`; mute + пауза во время показа |
| `adv.showFullscreenAdv` | только на логических паузах, свой троттлинг 2–3 мин |
| `getLeaderboards` | скор int32; таблицу создать в Консоли заранее |

Платежи — не в v1 (нужен сервер + договор ИП/самозанятого). Интерфейс `PlatformAPI` оставляет место.

Тестирование: черновик в Консоли + «Открыть с debug-панелью» (`?debug-mode=16`): `W` — ждёт init, `IT` — SDK ок, `IF` — ошибка.

### Бандл и загрузка (цель ≤ 5–10 МБ до играбельности)

- Phaser ~0,35 МБ + код ~0,15 МБ + стартовые атласы WebP ≤ 1 МБ + аудио ≤ 3 МБ ≈ **4–5 МБ до меню**.
- Атласы WebP через TexturePacker; аудио mono ogg+m4a парой, музыка 96–128 kbps, SFX ≤ 1 МБ суммарно, музыку грузить после меню.
- Отложенная загрузка: Boot → бар лоадера → стартовый пак → текстуры уровня N+1 фоново во время уровня N.
- Проверка: DevTools троттлинг Fast 3G, Lighthouse mobile.

### Пайплайн релиза

1. `vite build` → zip содержимого `dist/` (index.html в корне, без кириллицы в именах).
2. Консоль разработчика → черновик → загрузить архив.
3. Заполнить: название, «Об игре», «Как играть», категории, иконка + обложка (рисуются отдельно, не скриншоты), скриншоты реального геймплея ≥ 70% площади, возрастной рейтинг.
4. Локализация RU + EN (JSON по `i18n.lang`).
5. Модерация 3–5 рабочих дней. Закладывать 2–3 дня скоупа на стор-материалы.

## 4. Дорожная карта (после выбора концепции)

- **Неделя 1:** играбельный прототип кора одной сценой (без меты, без SDK) на реальном телефоне через черновик.
  - **Kill-гейт прототипа:** 5 из 5 тестировщиков объясняют правила после 10 сек наблюдения; средняя сессия ≥ 3 мин. Не проходит — режем/меняем концепцию до того, как вложены 6 недель.
- **Недели 2–3:** полный кор + LocalPlatform + облачные сейвы.
- **Недели 4–5:** мета/прогрессия, лидерборды, реклама, полировка фидбека.
- **Неделя 6:** баланс, RU+EN, иконка/обложка/скриншоты, черновик на модерацию.
- **После релиза:** итерации по метрикам; платежи/престиж/события — в v2.
