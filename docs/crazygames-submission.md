## ШАГ 0. Перед подачей: kill-гейт

QA CrazyGames оценит «понятность за 10 секунд». Перед сабмитом проверь сам:
покажи игру 3–5 людям, которые её не знают. Каждый должен понять «пропускай своих,
разворачивай самозванцев» за ~10 секунд без объяснений, и сессия ≥ 3 минут.
Если работает — иди дальше. Если нет — сначала правки онбординга.

## ШАГ 1. Аккаунт разработчика

1. Открой [developer.crazygames.com](https://developer.crazygames.com).
2. Войди обычным аккаунтом CrazyGames (или зарегистрируйся) — разработчик-режим
   включается на тот же аккаунт автоматически после входа.
3. Язык портала — можно переключить на русский, но поля игры заполняются по-английски.

## ШАГ 2. Создать игру

1. В портале: **Add new game** (или «Submit a game»).
2. Тип: **HTML5 game**.
3. Название: `Checkpoint` (остальные тексты позже, на шаге 6).

## ШАГ 3. Загрузить билд

1. Выбери файл `prohodnaya-yandex.zip` из корня проекта.
   - Это ровно тот же билд, что для Яндекса; платформа определяется в рантайме
     по домену, ничего пересобирать не нужно.
2. Дождись распаковки и превью игры прямо в портале. Игра должна загрузиться и
   работать (локальные сейвы — в localStorage, это штатно).

## ШАГ 4. Настройки игры в портале

| Настройка | Значение | Зачем |
|---|---|---|
| **Progress Save (Data Module)** | **Включить** | Облачные сейвы залогиненных игроков; без этого SDK вернёт `dataModuleDisabled`, гости останутся на localStorage-фолбэке |
| **Embed / Layout** | **Responsive + Portrait** | Игра адаптирована под любые экраны (колонка 720×1280 по центру, фон тянется) |
| **Ads** | Только SDK CrazyGames | Rewarded (детектор, продление, ×2, прощение) + midgame (выход с экранов результатов). Своих рекламных сетей нет и добавлять нельзя |
| **Category** | Puzzle | Альтернатива Casual |
| **Tags** | `casual`, `puzzle`, `logic`, `arcade`, `single-player`, `portrait`, `mobile-friendly` | |

## ШАГ 5. Обложки и видео

Загрузи из `docs/promo/` (имена файлов — как есть):

- **Covers:** `cover-landscape.png` (16:9) → `cover-portrait.png` (2:3) →
  `cover-square.png` (1:1). Требования CG выполнены: единый стиль, только
  название игры, без рамок/логотипов/плашек «new».
- **Preview videos:** `video-landscape.mp4` (1080p 16:9) → `video-portrait.mp4`
  (1080p 2:3). 15–20 с ✓, без звука ✓, ≤50 МБ ✓, первый кадр = обложка ✓,
  без чёрных полос/курсора/промо-текста ✓.

## ШАГ 6. Метаданные

Все тексты — копипастом из `docs/crazygames-meta.md`:

1. **Short description** — 1–2 предложения (EN).
2. **Description** — полный EN-текст с эмодзи-маркерами.
3. **Controls** — EN-блок управления (мышь/тап, ←/→).
4. Локализованные названия, если портал даст поля: Проходная / El Control /
   Le Contrôle / Kontrolle / Il Controllo / O Controle.

## ШАГ 7. Проверка перед сабмитом

1. **QA Tool** в портале — прогони автоматический чек-лист: фазы
   loading / gameplay / ads / data должны быть зелёными. Все вызовы SDK v3 уже
   на местах (`loadingStart/Stop`, `gameplayStart/Stop`, `happytime` — редко,
   rewarded+midgame с оверлеем и mute на `adStarted`, Data Module с фолбэком,
   Room Data для дуэлей, username через `user.getUser`).
2. Локальная проверка (опционально): `npm run dev` → открыть
   `http://localhost:5173/?platform=crazy` — SDK v3 включит local-режим
   (демо-реклама, демо-пользователь) без загрузки на портал.
3. По каждой rewarded-точке при `adError` должен появляться тост
   «Реклама недоступна», игра продолжается (кнопки не «пустышки»).

## ШАГ 8. Submit for review

1. Жми **Submit for review** (или «Submit game»).
2. Дальше — очередь на ревью QA-командой CG (обычно от нескольких дней до пары
   недель). Статус видно в портале.
3. Если придут замечания — правки делаем в репо (коммит → `npm run dist` →
   загрузить новый zip тем же способом), потом re-submit.

## ШАГ 9. После одобрения

1. Релиз согласуется с CG (дата/фичеринг); игра появится на площадке.
2. Обновления: пересобрать zip (`npm run dist`) → в портале загрузить как новую
   версию. Обложки можно обновлять (CG даже поддерживает A/B-тест обложек после лонча).
3. Следить: комментарии игроков, показатели первой сессии.

## Техническая часть: что уже сделано в коде (интеграция SDK v3)

| Требование CrazyGames | Реализация |
|---|---|
| `SDK.init()` до старта игры | `CrazyPlatform.init()` — до шрифтов и создания Phaser |
| `game.loadingStart()` при начале загрузки | сразу после `SDK.init()` (дальше грузятся шрифты/сессия) |
| `game.loadingStop()` при готовности игры | `ready()` → `game.loadingStop()` (фолбэк на легаси `loadingComplete`) |
| `gameplayStart()` / `gameplayStop()` | те же точки, что для Яндекса: вход заявки/старт забега — панели результатов/прерывание/меню |
| `happytime()` на достижениях, РЕДКО | новый личный рекорд блица, победа в дуэли, новое звание (по одному, не за каждую смену) |
| Rewarded через `ad.requestAd('rewarded')` | награда ТОЛЬКО в `adFinished`; звук глушится в `adStarted` (не на запросе — требование CG), возврат в `finally` |
| Midgame через `ad.requestAd('midgame')` | только на выходе с экранов результатов (та же политика, что interstitial Яндекса); unfilled/adCooldown не блокируют |
| Ad break: игра на паузе, UI заблокирован | оверлей + спиннер на всё время запроса/показа (rewarded и midgame), кнопки сцены недоступны до `adFinished`/`adError` |
| Adblock/unfilled: кнопки не «пустышки» | при `adError` — тост «Реклама недоступна» на всех rewarded-точках (детектор, ×2, прощение), игра продолжается |
| Data Module (прогресс) | `SDK.data.setItem/getItem` + localStorage-фолбэк `prohodnaya.cloud` |
| Язык игрока | `SDK.user.systemInfo.locale` (v3: environment — строка-режим!) → i18n на 7 локалей |
| Username в игре | `user.getUser()` при init → ник CG становится именем игрока (дуэли/топ-50), guests — сгенерированное имя |
| Room Data (Join/Invite) | хост комнаты: `updateRoom({roomId, isJoinable:true, inviteParams:{duel:код}})`; матч начался/отмена — `leftRoom()` |
| Зацикленность на их домене | SDK подгружается динамически только на `*.crazygames.com` в production (или `?platform=crazy`) |
| До геймплея ≤ 20 с | билд ~1.4 МБ распакованный, boot < 2 с даже на слабых устройствах |
| Только относительные пути | vite `base: './'` ✓ |
| Кнопка звука | Настройки → Звук вкл/выкл ✓ |
| `user-select: none` (мобильные) | в index.html с вендорными префиксами ✓ |
| Внешние ссылки/кросс-промо | нет ✓; своей fullscreen-кнопки нет ✓ (Escape/фуллскрин — на платформе) |

## Что НЕ трогать

- Не добавлять рекламные SDK, внешние ссылки, редиректы — мгновенный отказ QA.
- Не звать `happytime()` чаще (за смену/покупку — спам, требование «sparingly»).
- Не выключать локальный фолбэк сейвов: гости CrazyGames хранят прогресс
  в localStorage, залогиненные — в облаке Data Module.
